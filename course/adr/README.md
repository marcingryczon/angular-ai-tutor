# Architecture Decision Records

One file per decision that would be expensive to reverse. An ADR is short: what you decided, what
you compared it against, and what it cost. It is written **after** you have the experience to judge,
which is why the first one is the deliverable of Phase 13.

`000-TEMPLATE.md` is the shape. Number them in order; never edit a decided ADR, supersede it with a
new one that links back.
